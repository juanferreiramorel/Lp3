Manual de Usuario: Crear Orden de Compra

Este documento explica paso a paso cómo registrar una nueva orden de compra en el sistema.

Formulario de Registro

Al ingresar a la opción "Agregar Nuevo", se presentará el siguiente formulario:

Pasos para el Registro

  1. Seleccionar Proveedor: Elija el proveedor al cual se le realizará el pedido desde la lista desplegable.
  2. Fecha de Orden: Por defecto aparece la fecha actual, pero puede modificarla si es necesario.
  3. Sucursal: Seleccione la sucursal para la cual es el pedido.
  4. Observaciones: (Opcional) Agregue cualquier nota relevante para la orden.

Agregar Productos

En la sección de detalle:

  1. Busque el producto por nombre o código en el campo de búsqueda.
  2. Ingrese la Cantidad requerida.
  3. Verifique el Precio Unitario (puede ajustarlo si ha cambiado).
  4. El subtotal se calculará automáticamente.
  5. Para agregar más productos, repita el proceso en las siguientes líneas o presione el botón "+" si está disponible.

Finalizar

Una vez cargados todos los datos, presione el botón "Guardar" al final del formulario para registrar la orden de compra. Si desea descartar los cambios, presione "Cancelar".
